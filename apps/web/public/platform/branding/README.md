# Platform branding assets (ThinkAIQ CRM)

Official ThinkAIQ mark (question-mark + profile + circuit lightbulb).

Platform assets live under `/platform/branding/` — **not** under `tenants/{tenantId}/…`.

| File | Role |
|------|------|
| `logo-mark-on-light.png` | Official mark on white (default shell / login) |
| `logo-mark-on-dark.png` | Official mark on dark (dark chrome) |
| `logo-mark.png` / `logo.png` | Default light mark (web-optimized) |
| `favicon.ico` / `favicon.png` | Browser tab icon |
| `app-icon.png` | Apple touch / PWA icon |
| `og-image.png` | Default Open Graph image |
| `site.webmanifest` | Install metadata |
